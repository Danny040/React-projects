# Web Development Projects – Full Stack & React
This repository showcases a selection of my web development projects built using React, Node.js, and Express, ranging from full stack applications to frontend-only interfaces. Each project reflects my growth as a software engineering student, covering key areas like component-based design, backend integration, user interaction, and UI theming.

---

# Included Projects
* Pet Clinic (Full Stack)
  * Full stack app using React for the frontend and Node.js + Express for the backend. Users can add, view, and manage pet profiles and appointments. Designed to simulate a small-scale clinic dashboard.

* To-Do App (React)
  * A lightweight task management app built with React.js. Users can add, complete, and delete tasks in a clean, interactive interface that demonstrates state management and component logic.

* Portfolio Website (React)
  * A personalized, retro-styled portfolio site built with React. Features an animated boot sequence, project explorer, BIO section, and contact form. Built to reflect both technical skills and personal creativity.

* Technologies Used
React.js • Node.js • Express • REST APIs • JavaScript • HTML • CSS • Component Design • UI Theming • Git
